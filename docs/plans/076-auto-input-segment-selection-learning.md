# PLAN-076 · AutoInput 分段选词与整词学习

## 0. 变更摘要

为输入人名、地名和未收录词提供一次性的“分词选字”操作：从完整拼音候选切到当前首音节，确认该字后锁定前缀，自动恢复剩余拼音的整体预测；用户可以重复分词，也可以一次选完后缀。完整结果作为同一次组合上屏，并学习最终文字与读音，提高后续全拼、简拼和混输下的个人排名。

独立于 [073 拼音质量](https://github.com/auto-stack/auto-os/blob/main/docs/plans/archived/073-autoime-pinyin-quality.md)，原因是本包增加交互状态、原生候选窗操作、TSF 提交与学习事务、误学撤销，不能用“已有学习选项开启”代替功能交付。073 的 Shift 修复、常用词排序及原有验收均保留，073 不等待本包。

## 1. 目标

- `shide` → 分词 → 只选 `shi` 的字 → 选「是」后显示 `是 de` → 选「的」→ 单次提交「是的」。选定「是」时没有独立正文提交。
- `zhangruolan` → 分词选「张」→ 自动给出 `ruolan` 的后缀候选；可以直接选「若兰」，也可以再次分词选「若」后继续选「兰」。两条路径最终结果一致。
- 最终确认后学习完整词及实际读音；新词可进入自然拼音候选，已有词个人权重提高，重开引擎仍有效。取消、错误提交和撤回的中间组合不增加本次整词学习。
- 学习数据与 `custom_phrase.txt` 显式短码分开；提供最小“忘记学习”入口，能撤销指定词和读音的个人学习而不删除系统词或其他读音。

本包交付 Windows x64 原生候选窗和离线输入流程。默认 Tab，支持配置为竖线字符 `|`；候选窗提供“分词”按钮。协议/状态/词条读音不绑定 Windows，供未来 Linux 复用，但 Linux 宿主不在本次验收范围。AI 专名词库、云同步、完整学习词库管理界面与整句模型升级留待后续；不依赖 AutoUI、AGE、新版 A2R 或旧 AutoVM/A2R。

## 2. 架构方案

现有 TSF KeyRouter/候选窗动作 → 引擎适配层中的分段会话 → librime 音节与词典候选 → 预编辑快照 → TSF 组合更新。只有最终结果成功提交后才确认本次完整词的学习。已确认前缀、未确认原始输入范围、候选页版本、焦点代次及本次学习状态都绑定同一组合，不能用多个相互无关的输入会话拼接结果。

优先使用锁定版本 librime 的音节导航、候选选择和原生用户词典。T-01 必须验证候选范围、选择后的自动恢复及学习时机；如果默认组件不足，在 AutoInput 的适配层或随包 Rime 扩展中补最小能力，并记录扩展接口与离线依赖。不得在 Win32 绘制层伪造词条、拿单字顺序直接拼出错误读音，或另写一套与 librime 不一致的权重库。

当前按键链沿既有 C++ 实现，配置和词库沿共享 Rime 资源。确需新增管理业务脚本时使用新版 ACE AV；核心选词和学习不引入管理进程调用或逐键 VM 启动。

## 5. 详细设计

### 交互状态与按键

以下状态为设计语义，不强制实现类名。Confirmed prefix 始终在同一 TSF composition 中，预编辑文字不等于已提交正文。

| 状态/输入 | 转换与候选 | 提交/学习 |
|---|---|---|
| 自动候选，剩余至少两个可解析音节；Tab 或分词按钮 | 聚焦剩余部分的首音节，显式高亮其范围，候选限定为该音节的字；保留剩余拼音 | 无 |
| 局部选字；数字/空格/鼠标选字 | 确认当前音节并锁定文字前缀，自动恢复剩余输入的正常整体候选 | 有剩余时无；无剩余时走最终确认 |
| 已有前缀，自动候选；选中后缀词 | 在已确认前缀后继续确认对应范围；未消费的输入仍参与自动候选 | 只有整个组合确认后提交一次 |
| 局部选字；再次分词 | 退出本次局部模式，恢复同一未确认输入的整体候选，未选字不推进音节 | 无 |
| 原始拼音内 Backspace/Delete | 保持正常拼写编辑，失效的候选和读音映射重新生成 | 无 |
| 光标移到锁定前缀与未确认输入的边界后 Backspace | 撤销上一段确认，将该段原始拼音恢复到待选区，并重算后缀 | 无；已撤销结果不学习 |
| Esc、失焦、宿主结束组合 | 沿既有取消合同撤销本次未提交组合、恢复原选区；无跨焦点残留 | 不学习本次完整词 |
| Enter 原文提交或其他既有非候选提交 | 保持原有含义，退出分段状态 | 原始拼写不作为新词学习 |
| 英文、无组合、敏感输入或引擎未就绪 | 分词绑定不截获宿主键；按钮不显示或不可操作 | 无 |

默认 Tab 只在适用的中文组合中执行本动作，局部状态再次 Tab 退出。单音节无需分词，维持既有按键规则，不丢失输入；无法确定有效音节时不篡改原串。Shift+Tab 维持既有导航含义；T-01 必须核验当前 Tab 配置的覆盖次序，不能叠加两次导航。

可选竖线绑定通过用户配置选择，按**转换后的字符与修饰键**识别；仅在适用组合中触发，其余按正常符号处理，默认 Tab 时竖线仍是普通符号。不劫持 Ctrl/Alt/Win/AltGr。两个绑定切换的配置键、允许值、错误值回退到 Tab 及加载时点由 T-02 固定在 shared 资源说明，并提供可复制配置示例；本次不要求设置 GUI。

按钮点击不能取得编辑器焦点。其事件与选词事件一样绑定组合/焦点代次及候选版本；旧页面的点击、重复 Test 回调或迟到的编辑请求不能推进新组合或重复学习。既有 UI Snapshot 补充需要的模式与范围，绘制层只展示引擎/会话状态。

### 音节与后缀预测

按音节图和已选候选的消耗范围定位，保留原始键串与实际读音的对应关系。`shi` 不拆成 `s/h/i`，`xian` 不无条件拆成 `xi/an`；显式 `xi'an` 必须保留边界。简拼 `sd`、混输 `shid/shde` 允许首段有多个读音解释，候选确认后才能确定消耗范围与完整读音，不能把用户码串直接充当词典的拼音键。

选定前缀后，后缀候选继续服从已确定的读音/文本约束；允许剩余词一次确认。本包要求可连续输入既有支持的组合长度，不额外引入“只支持两字/三字”的限制；测试覆盖二字、三字及更长组合。候选的文字、页内标签、选中消耗范围必须一致。

### 学习、排序与纠错

一次造词的身份是“最终文字＋实际规范音节序列”，包括多音字实际读音。普通短词/名字采用整次组合为学习单位；没有用词边界证据时，不把长句里的任意子串全部加入词库。T-01 核对现有引擎的词长与整句学习规则，记录适用范围；不得只学独立单字而遗漏本次完整结果。

| 阶段 | 必须满足的学习语义 |
|---|---|
| 查看候选、局部确认、撤回、取消 | 不增加本次完整词频；已有用户库内容不受破坏 |
| 最终候选确认，宿主提交待决 | 本次新增完整词学习处于待确认状态；TSF 同步或异步成功结果才允许确认 |
| 宿主成功接收最终文本 | 本次词频增加一次；新词进入用户词典，已有词沿原生权重模型提升；重复回调不重复计数 |
| 宿主拒绝/编辑请求失败或上下文过期 | 不生成成功学习；清理待确认状态，不在下一组合补写旧结果 |
| 正常退出并重开 | 已成功学习的完整词和读音可读取，全拼/简拼/混输均通过正常拼音索引召回 |
| 忘记学习 | 移除指定文字＋读音的个人学习贡献；系统词回归基础排名，新造词不再凭该学习记录出现；其他词/读音/显式短码保留 |

先验证原生学习行为；若引擎已经在宿主成功前更新词频，T-01 必须给出可实现的延迟确认或受限回滚方案，并测取消反例。不能再追加一次手工学习造成双计数，也不能为解决一个组合的取消而恢复整份用户库、覆盖其他会话的学习。这里只承诺正常进程生命周期内的确认/取消语义，不声称跨崩溃的宿主正文与词库具有分布式原子提交。

使用频率与近期使用权重优先沿现有引擎模型。首次成功造词后即能召回，重复选择应改善排名；不承诺所有歧义简拼一次造词就永久首选。用冻结的低频合成词和同码对照证明效果，不能通过固定置顶满足测试。

最小“忘记学习”入口放在候选操作中，对确实有个人学习记录的词及读音启用；来源或读音不明确时不能猜测删除。底层接口可供未来管理器复用。它不等同于删除系统词、永久屏蔽词或操作 `custom_phrase.txt`。全量浏览、编辑、导入学习词的 GUI 后续单独扩展 [074](074-auto-input-av-phrase-ui.md)，不是本包前置。
